# Поиск научных статей

Два открытых источника, ключ не обязателен. Запускай оба параллельно отдельными вызовами: выдача и сбои у них независимы.

```bash
python3 "${CLAUDE_SKILL_DIR}/scripts/search.py" cyberleninka --query "терминологическая эквивалентность" --limit 10 --page 1
python3 "${CLAUDE_SKILL_DIR}/scripts/search.py" openalex --query "terminological equivalence philosophical translation" --limit 10 --page 1
```

`--limit` от 1 до 50. «Ещё» означает тот же запрос с `--page 2`. `--year-from 2020` и `--year-to 2000` ограничивают годы включительно, в обоих источниках, по отдельности или вместе; без них годы не ограничены. `--vak-only` только для `cyberleninka`: оставляет журналы из перечня ВАК, так отвечай на «есть ли статьи ВАК по». Аннотации в выдаче обрезаны до 320 символов, полный текст по ссылке.

## Источники

- КиберЛенинка: русскоязычные журналы с полными текстами в открытом доступе, у журналов из перечня стоит «ВАК». Это внутренний поиск сайта, а не документированный API, при частых запросах включается капча. Несколько запросов за раз, без циклов по страницам.
- OpenAlex: мировая база, российские журналы представлены не все. Англоязычную литературу ищи английским запросом. Скрипт берёт ключ из переменной `OPENALEX_API_KEY`, а на macOS ещё из связки ключей (сервис `openalex-api-key`), и шлёт его заголовком: с ключом около 1000 поисков в сутки, без ключа около 100 и предупреждение `openalex_without_api_key` в stderr. Добавить или заменить ключ пользователь запускает сам в своём терминале, не через агента: `security add-generic-password -U -a "$USER" -s openalex-api-key -w` (`-w` последним, тогда ключ спрашивается и не попадает в историю шелла). Сам ключ в файлы и чат не выводи.

## Как работать

1. Запрос из двух-четырёх содержательных слов. Для OpenAlex дай английский вариант, если тема не сугубо русская.
2. Покажи отобранное: название, авторы, год, журнал, ссылка и одна строка о том, чем статья подходит к теме. Только то, что есть в выдаче, ничего не достраивай по памяти. Том, номер и страницы для библиографической ссылки даёт только OpenAlex; у КиберЛенинки их в выдаче нет, так и скажи.
3. Одна и та же статья может прийти из обоих источников: показывай её один раз, с обеими ссылками.
4. Скрипт сам повторяет сетевые сбои и 5xx, упавший запрос вручную не перезапускай. `RateLimitError` значит 429: у OpenAlex кончился суточный бюджет, когда он откроется, видно по заголовкам в тексте ошибки. Ошибка «вернул не JSON» у КиберЛенинки обычно значит капчу: в этой сессии КиберЛенинку больше не вызывай, продолжай на OpenAlex и дай ссылку `https://cyberleninka.ru/search?q=<запрос>` для поиска вручную.

eLibrary сюда не входит: его правила запрещают автоматический поиск, нарушителей блокируют по IP.
